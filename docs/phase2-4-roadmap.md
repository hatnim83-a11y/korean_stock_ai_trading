## Phase 2: 테마 카테고리 분류

### 목표
테마를 산업 카테고리로 자동 분류하여 포트폴리오 다양성 보장

### 배경
- 현재 `themes.category` 컬럼 존재 (DB v10), 대부분 '기타'로 저장됨
- `_select_with_diversity()`에서 `MAX_THEMES_PER_CATEGORY = 2` 적용 중
- 카테고리가 제대로 분류되면 같은 섹터(반도체 3개 등) 집중 방지 가능

### 구현 방향
- 테마명 → 카테고리 매핑 테이블 (반도체, 에너지, 바이오, 방위, IT/SW, 소비재, 기타)
- 크롤링 시 자동 분류 (키워드 기반 + AI 폴백)
- `selector.py` 다양성 로직 강화

### 예상 변경 파일
- `modules/theme_analyzer/crawlers.py` — 카테고리 매핑
- `modules/theme_analyzer/selector.py` — 다양성 로직 개선
- `database.py` — category 저장 활용

## Phase 3: S커브 모멘텀 스코어링

### 목표
모멘텀 점수를 선형에서 S커브(시그모이드)로 변경하여 극단값 영향 완화

### 배경
- 현재: 선형 매핑 (-10%→0점, +10%→25점)
- 문제: +3%와 +5%의 점수 차이가 +8%와 +10%의 차이와 동일
- 실제: 낮은 모멘텀에서의 차이가 높은 모멘텀에서의 차이보다 중요

### 구현 방향
```
S커브: score = MAX * sigmoid(k * (return - midpoint))
- midpoint = 0% (중심)
- k = 0.5~0.8 (기울기, 데이터 기반 조정)
```
- 0% 근처에서 민감하게 반응, 극단값에서는 둔감
- Phase 1 과열 감점과 상호보완적

### 예상 변경 파일
- `modules/theme_analyzer/scorer.py` — `calculate_momentum_score()` S커브 적용

## Phase 4: 일관성(Consistency) 점수

### 목표
단기 급등보다 꾸준히 상승하는 테마에 가산점 부여

### 배경
- 현재: 5일 평균 수익률만 반영
- 문제: 4일 하락 + 1일 급등 = 5일간 완만한 상승 → 같은 점수
- 전자는 변동성 높고 위험, 후자는 안정적 추세

### 구현 방향
- 일별 수익률의 표준편차 → 변동성 패널티
- 연속 상승일수 → 일관성 가산점
- 5일 중 양수일 비율 → 안정성 지표
- 최대 5~10점 범위

### 예상 변경 파일
- `modules/theme_analyzer/scorer.py` — `calculate_consistency_score()` 신규
- `modules/theme_analyzer/scorer.py` — `score_themes()` 통합
- `modules/theme_analyzer/crawlers.py` — 일별 데이터 수집 보강
