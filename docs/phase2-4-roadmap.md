## 완료된 Phase

### Phase 1: 과열 감점 + 배점 조정 (2026-03-09)
- 모멘텀(25) + 과열감점(0~-15) + 뉴스(15) + AI감성(10) + 종목수(5) + 기본(10) = 최대 65점
- 과열 감점: 5일 수익률 +8% 이상 시 선형 감점, +15%에서 -15점(최대)
- 3일/5일 급가속 추가 -3점
- MIN_SELECTION_SCORE: 30.0

### Phase 1.5: 테마 연장 (2026-03-09)
- 화요일 재선정 시 기존 테마 점수 >= RETENTION_SCORE(38.0)이면 슬롯 유지
- 신규 진입 30+ / 유지 38+ 비대칭 설계

### Phase 2: 카테고리 분류 (2026-03-09)
- 7개 카테고리: 반도체, 2차전지/에너지, 바이오, IT/SW, 방위/우주, 소비재, 산업재 + 기타
- 키워드 매칭 자동분류 (`classify_theme_category()`)
- MAX_THEMES_PER_CATEGORY=2 다양성 제한

### Phase 2.5: 파이프라인 강화 (2026-03-13)
3가지 핵심 결함 수정:
1. **AI 감성분석 정상화**: `crawl_theme_news()` → 뉴스 텍스트 수집 → AI가 실제 분석 (기존 항상 5.0점 반환 해결)
2. **모멘텀 정확도 개선**: `_enrich_theme_stocks()` → URL에서 종목코드 매핑 → KIS API 5일 수익률 계산
3. **화요일 실시간 보강**: `_enrich_tuesday_themes()` → DB 가중평균에 실시간 모멘텀/AI 조건부 보정
   - 모멘텀 delta > 3%p → 점수 보정 (delta × 1.5)
   - AI delta > 2점 → 점수 보정

## 미착수 Phase

### Phase 3: S커브 모멘텀 스코어링

**목표**: 모멘텀 점수를 선형에서 S커브(시그모이드)로 변경하여 극단값 영향 완화

**배경**:
- 현재: 선형 매핑 (-10%→0점, +10%→25점)
- 문제: +3%와 +5%의 점수 차이가 +8%와 +10%의 차이와 동일
- 실제: 낮은 모멘텀에서의 차이가 높은 모멘텀에서의 차이보다 중요

**구현 방향**:
```
S커브: score = MAX * sigmoid(k * (return - midpoint))
- midpoint = 0% (중심)
- k = 0.5~0.8 (기울기, 데이터 기반 조정)
```

**변경 파일**: `modules/theme_analyzer/scorer.py` — `calculate_momentum_score()`

### Phase 4: 일관성(Consistency) 점수

**목표**: 단기 급등보다 꾸준히 상승하는 테마에 가산점 부여

**배경**:
- 현재: 5일 평균 수익률만 반영
- 문제: 4일 하락 + 1일 급등 = 5일간 완만한 상승 → 같은 점수
- 전자는 변동성 높고 위험, 후자는 안정적 추세

**구현 방향**:
- 일별 수익률의 표준편차 → 변동성 패널티
- 연속 상승일수 → 일관성 가산점
- 5일 중 양수일 비율 → 안정성 지표
- 최대 5~10점 범위

**변경 파일**: `modules/theme_analyzer/scorer.py` — `calculate_consistency_score()` 신규

### Phase 5: Dual Momentum (신규 전략 후보)

**목표**: 절대 모멘텀 + 상대 모멘텀을 결합한 월간 리밸런싱 전략

**개요**:
- 절대 모멘텀: 12개월 수익률이 양수인 종목만 매수 (하락장 방어)
- 상대 모멘텀: 상위 10개 종목 선택 (강세 종목 집중)
- 월 1회 리밸런싱 (낮은 거래 비용)

**현 테마 전략과 차이점**:
| 항목 | 테마 전략 (현재) | Dual Momentum |
|------|----------------|---------------|
| 리밸런싱 | 주 1회 (화요일) | 월 1회 |
| 종목 선택 | 테마 기반 | 개별 종목 모멘텀 |
| 시장 방어 | 과열 감점 | 절대 모멘텀 필터 |
| 보유 기간 | 7~14일 | 1개월 |

**상태**: 백테스트 미실시. 현 전략(+337%, MDD -7.9%)이 충분히 우수하여 우선순위 낮음.
