- **손절**: 진입가 - 2×ATR

- **청산**: 10일 저가 이탈 시 매도 (터틀 방식)
- **손절**: 진입가 - 2×ATR
- **사이징**: 균등 배분 (슬롯 수 기준)
- **보유 제한**: 없음
- **결과**: 기존 대비 27배 수익, MDD 절반

### 3. 테마진입 + 터틀청산 (ATR 사이징)
- 2번과 동일하되 ATR 기반 포지션 사이징 적용
- 균등배분 대비 약간 낮은 수익 (변동성 큰 종목에 적게 투자)

### 4. 하이브리드 (테마 + 20일 돌파필터)

## 핵심 인사이트

### 왜 터틀 청산이 효과적인가?

**기존 문제점**: 14일 최대 보유 제한
- 수익 나는 종목도 14일에 강제 매도
- 승률은 높지만(45.8%) 평균 수익이 작음
- 손익비 1.20 → 수수료/슬리피지 포함하면 거의 제로섬

**터틀 10일 저가 청산의 장점**:
- 추세가 지속되면 무제한 보유 (평균 92일)
- 승률은 낮지만(39.3%) 이긴 거래의 수익이 큼
- 손익비 5.67 → 1번 수익이 5번 손실을 커버
- "이익은 달리게 하고 손실은 빨리 끊는다"

### 수치 비교

```
기존 전략:
  승률 45.8% × 평균 수익 +5.4% = 기대수익 +2.47%
  패률 54.2% × 평균 손실 -4.5% = 기대손실 -2.44%
  순 기대값 ≈ +0.03% (거의 0)

터틀 청산:
  승률 39.3% × 평균 수익 +28.5% = 기대수익 +11.2%
  패률 60.7% × 평균 손실 -5.0% = 기대손실 -3.0%
  순 기대값 ≈ +8.2% (매매당)
```

## 터틀 트레이딩 핵심 규칙 (Richard Dennis, 1983)

### 진입 규칙
- **S1 (단기)**: 종가가 20일 최고가를 돌파하면 매수
- **S2 (장기)**: 종가가 55일 최고가를 돌파하면 매수
- 직전 S1 신호가 수익이었으면 해당 신호 건너뜀 → S2로 진입

### 청산 규칙
- **S1**: 10일 최저가 이탈 시 매도
- **S2**: 20일 최저가 이탈 시 매도
- 손절: 진입가 - 2×ATR (무조건 실행)

### 포지션 사이징
- 1유닛 = (총 자본 × 1%) ÷ ATR(14일)
- 변동성 높은 종목 → 적은 수량, 낮은 종목 → 많은 수량
- 같은 방향 피라미딩: 0.5ATR 상승마다 최대 4유닛 추가

### 실전 적용 시 고려사항
- 순수 터틀의 20일 돌파 진입은 우리 시스템(테마 기반)과 상충
- **10일 저가 청산**만 적용하면 기존 테마 선정의 장점 + 추세 추종 청산의 장점 결합
- ATR 사이징은 균등배분과 큰 차이 없음 (소액 운용 시 의미 제한적)
