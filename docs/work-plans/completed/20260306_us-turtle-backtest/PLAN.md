# PLAN: 미국 주식 터틀 트레이딩 백테스트

## 목표
S&P 500 대상 순수 터틀 트레이딩 백테스트를 실행하여, 미국 시장에서 터틀 전략의 유효성을 검증한다.

## 배경
- 한국 시장(38종목)에서 순수 터틀은 +136.8%로 기존 최적화(+336.9%) 대비 열위
- 원인: 종목 수 부족(20일 돌파 신호 286건/3년)
- 미국 S&P 500(~500종목)이면 돌파 신호가 충분히 발생할 것으로 예상
- 터틀 트레이딩은 원래 미국 선물 시장에서 탄생한 전략

## 비교 전략 (3가지)

| # | 전략 | 진입 | 청산 | 사이징 |
|---|------|------|------|--------|
| A | 순수 터틀 | 20일 고가 돌파 | 10일 저가 이탈 + 2xATR 손절 | ATR 기반 |
| B | 터틀+모멘텀필터 | 20일 돌파 + MA200 위 + 거래량 | 10일 저가 이탈 + 2xATR 손절 | ATR 기반 |
| C | Buy & Hold SPY | SPY 매수 후 보유 | - | 전액 |

## 파라미터

| 항목 | 값 |
|------|-----|
| 초기 자본 | $10,000 |
| 기간 | 2021-01-01 ~ 2026-01-31 (5년) |
| 종목 풀 | S&P 500 |
| 최대 포지션 | 20개 |
| 돌파 기간 | 20일 |
| 청산 기간 | 10일 |
| ATR 손절 배수 | 2.0 |
| 리스크/거래 | 자본 1% |
| 수수료 | 0 (미국 주요 브로커 무료) |
| 슬리피지 | 0.05% |

## 구현 단계

### Step 1: S&P 500 종목 리스트 확보
- 위키피디아 또는 하드코딩으로 티커 리스트 획득

### Step 2: 백테스트 스크립트 작성
- scripts/backtest_us_turtle.py 생성
- yfinance로 데이터 로드
- 3전략 순차 실행 + 비교 테이블 출력

### Step 3: 실행 및 결과 문서화
