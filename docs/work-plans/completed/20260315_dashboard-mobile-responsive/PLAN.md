# PLAN: 대시보드 모바일 반응형 개선

## 목표
`stock.jjjforever.com` 대시보드를 모바일 웹(375px~)에서도 편하게 사용할 수 있도록 반응형 CSS 개선

## 배경
- Cloudflare Tunnel로 외부 접근 가능해짐 → 모바일 접속 빈도 증가 예상
- 현재 768px breakpoint 1개만 존재, 테이블은 수평 스크롤에만 의존
- 포트폴리오 테이블 10개 열 → 모바일에서 거의 사용 불가

## 변경 파일
- `web/templates/dashboard.html` — CSS + 모바일 테이블 JS 렌더링
- `web/templates/login.html` — 로그인 박스 고정 너비 해제

## 구현 단계

### Step 1: 로그인 페이지 모바일 대응
- [ ] `login.html` — width:380px → max-width:380px + width:90% 변경
- [ ] 패딩 축소: 48px 40px → 모바일 시 32px 24px

### Step 2: 대시보드 CSS 반응형 강화
- [ ] breakpoint 추가: 480px (모바일 세로), 768px (태블릿), 기존 유지
- [ ] 헤더: 모바일 시 패딩/폰트 축소
- [ ] 탭: 모바일 시 터치 영역 확보 (최소 44px 높이)
- [ ] 요약 카드: 모바일 시 2열 → 480px 이하 1열
- [ ] 카드 값 폰트 축소: 1.4rem → 모바일 1.1rem
- [ ] 테마 카드 minmax 축소: 260px → 모바일 적합
- [ ] 시스템 그리드: 768px 이하 1열 (이미 존재)
- [ ] 필터 select/input: 모바일 시 터치 친화 높이

### Step 3: 포트폴리오 테이블 모바일 카드 뷰
- [ ] 768px 이하에서 테이블을 카드형 레이아웃으로 변환 (CSS only)
- [ ] 각 행이 독립 카드로: 종목명(상단), 수익률/수익금(강조), 기타 정보(하단)
- [ ] 데스크톱에서는 기존 테이블 유지

### Step 4: Trades 테이블 모바일 대응
- [ ] 768px 이하에서 카드형 변환
- [ ] 핵심 정보(종목, 매매, 수익률) 강조, 나머지 축소

### Step 5: 차트/뉴스 모바일 최적화
- [ ] 차트 컨테이너 패딩 축소
- [ ] 뉴스 아이템 패딩 조정

## 접근 방식
- CSS-only 반응형 (JS 변경 최소화)
- 테이블 → 카드 변환은 CSS `display:block` 트릭 사용
- 기존 데스크톱 레이아웃 변경 없음

## 롤백 계획
- `dashboard.html`, `login.html` git checkout으로 즉시 복원 가능
- systemd restart만으로 반영

## 완료 기준
- iPhone SE(375px), iPhone 12(390px), Galaxy(360px) 사이즈에서 가독성 확보
- 포트폴리오/Trades 테이블이 수평 스크롤 없이 모바일에서 읽히는지 확인
- 데스크톱(1400px) 기존 레이아웃 변경 없음
