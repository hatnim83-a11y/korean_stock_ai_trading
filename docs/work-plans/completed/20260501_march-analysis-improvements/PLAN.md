# 3월 실전 분석 및 수익률 개선 계획 (최종안)

## Context

3월 실전 데이터 + 코더/플래너 에이전트 리뷰를 종합한 최종안.

**핵심 진단**: 익절 전략(+471,450원)은 우수하나, 손절(-453,200원)이 거의 전부 상쇄. 손절 6건 중 5건의 `max_profit_during_hold = 0%` — 이는 손절 기준이 아닌 **진입 타이밍** 자체가 문제.

## 3월 실전 데이터 핵심

| 항목 | 수치 |
|------|------|
| 월초→월말 | 4,176,531 → 4,592,374원 (+4.22%) |

| 손절 손실 합계 | -453,200원 |
| 손절 후 D+1 반등 평균 | +15.8% (6건 중 5건 반등) |
| 손절 종목 max_profit=0% | 5/6건 (진입 직후 하락) |

## 개선 전략 (리뷰 반영 최종안)

### 1. 손절 보호기간 — 매수 후 1일간 -8% (기존 ATR 기반 → -8%)

**변경 전**: `_check_stop_loss()`에서 `pos.current_price <= pos.stop_loss_price` (ATR 기반, 실질 -5%~-8%)
**변경 후**: `hold_days <= 1`이면 `pos.buy_price * 0.92` (-8%)와 비교, 이후 기존 ATR 손절가 적용

- 리뷰 반영: -10%는 과도 → **-8%로 축소** (플래너 권고). 갭다운 슬리피지(-9.55% 실전 평균)와의 균형
- MarketGuard CRISIS 시 보호기간 무시 (안전장치)
- 구현: `portfolio_monitor_v2.py:_check_stop_loss()` 내부에서 동적 비교 (기존 `stop_loss_price` 미변경)
- **코더 발견**: `STOP_LOSS_FAST`(-7%)는 데드 코드. 실제 손절은 ATR 기반. Grace Period는 이 ATR 손절가보다 넓으면 보호 역할을 함

**수정 파일**:
- `config.py` — `GRACE_PERIOD_DAYS = 1`, `GRACE_PERIOD_STOP_LOSS = -0.08`
- `portfolio_monitor_v2.py` — `_check_stop_loss()` 수정

### 2. 트레일링 L1 폭만 조정 (활성화 기준은 유지)

**변경 전**: L1 활성화 +8%, 고점 대비 -5%
**변경 후**: L1 활성화 **+8% 유지**, 고점 대비 **-4%**

- 리뷰 반영: **활성화 +10% 상향은 취소** — 최대수익 9.2~9.9% 종목이 L1 미발동 → 손절 역전 위험 (플래너 경고). +8% 유지.
- 폭만 -5% → -4%로 축소 — 수익 반납 방지. HJ중공업 케이스에서 +12.75% → +6.57% 대신 +8.75%에서 청산 가능

**수정 파일**:
- `config.py` — `TRAIL_LEVEL1_PCT = 0.04` (0.05에서 변경)
- 배포 시점: **장 마감 후** (기존 L1 활성 포지션에 즉시 영향)

### 3. 테마/섹터 분산 — 동일 섹터 내 포지션 제한

**변경 전**: 테마당 종목 수 제한 없음 (MAX_THEME_WEIGHT=40% 있으나 미적용)
**변경 후**: 동일 테마 최대 2종목 + 상위 섹터 최대 3종목

- 리뷰 반영: 단순 테마 2종목 하드캡은 백테스트에서 -43p 수익 하락. **섹터 레벨 제한 병행**이 핵심 (플래너 제안)
- "반도체" + "반도체 장비" + "HBM" = 같은 섹터. 3/4 동시 손절의 근본 원인
- 이미 존재하는 `category` 필드 활용 (crawlers.py의 `_PREDEFINED_THEMES`에 7개 카테고리 정의)

**수정 파일**:
- `config.py` — `MAX_STOCKS_PER_THEME = 2`, `MAX_STOCKS_PER_SECTOR = 3`
- `main.py` — `execute_buy_orders()` Phase 5~6 사이에 테마/섹터 분산 필터

### 4. (신규) 진입 타이밍 강화 — max_profit=0% 방어

**근거**: 손절 6건 중 5건의 `max_profit_during_hold = 0%`. 매수 후 단 한 번도 수익을 내지 못함. 이는 손절 기준이 아니라 진입 자체의 문제.

**변경**:
- 모닝필터 체결강도 기준 강화: `MIN_STRENGTH = 45` → `50` (매도우위 종목 추가 차단)
- 전일 대비 갭다운 -2% 이상 종목은 당일 진입 보류 (기존 갭 필터 -3%보다 보수적)
- 이유: 3/4 갭다운 손절 종목들은 전일 갭이 이미 -5% 이상이었을 가능성 높음

**수정 파일**:
- `config.py` — `MIN_STRENGTH = 50`, `MAX_GAP_DOWN_PERCENT = 2.0` (3.0에서 변경)
- `modules/morning_filter/morning_screener.py` — 갭다운 기준 참조

### ~~전략 4 (기존): 모멘텀 소진 조기 청산~~ → **제거**

- **코더 발견**: `MAX_HOLD_DAYS_LOSS=5` + `MIN_PROFIT_FOR_LONG_HOLD=0.03`이 이미 동일한 로직을 구현하고 있음
- **플래너 판단**: 미드위크 교체 로직과도 중복. 추가 구현 불필요

## 전략 간 상호작용 검증

| 조합 | 상호작용 | 판정 |
|------|---------|------|
| 보호기간 + L1 폭 축소 | 초기 손절 완화 + 수익 구간 보호 강화. 시너지 양호 | OK |
| 보호기간 + 섹터 분산 | 진입 종목 분산 + 초기 손절 완화. 상호 보완 | OK |
| L1 폭 축소 + 진입 강화 | 독립적. 충돌 없음 | OK |
| 4개 동시 적용 | 보호기간(-8%) + 진입 강화(갭 -2% 차단)가 이중 방어. 과도하지 않음 | OK |
