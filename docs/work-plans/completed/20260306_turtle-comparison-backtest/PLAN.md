# PLAN: 터틀 트레이딩 동일 조건 백테스트 비교

## 목표
기존 최적화 전략(+337.11%)과 터틀 청산 전략을 **완전히 동일한 조건**에서 비교하여 청산 방식의 순수 효과를 측정한다.

## 배경
- 이전 터틀 백테스트(`backtest_turtle.py`)에서 기존 전략이 +4.0%로 나옴
- 실제 기존 백테스트(`backtest_live_logic.py`)에서는 +337.11%
- 원인: 포지션 사이징(균등 vs 가중치), 종목 점수 계산 등이 달랐음
- 동일한 엔진에서 청산 방식만 바꿔야 공정한 비교 가능

## 비교 전략 (4가지)

| # | 전략 | 진입 | 사이징 | 청산 | 보유제한 |
|---|------|------|--------|------|---------|
| A | 기존 최적화 (기준선) | 테마+필터+점수 | 점수 가중치 | 트레일링 L1/L2/L3 + -7% 손절 | 14일 |
| B | 테마+터틀청산 | 테마+필터+점수 (A동일) | 점수 가중치 (A동일) | 10일 저가 이탈 + 2xATR 손절 | 14일 |
| C | 테마+터틀청산+무제한 | 테마+필터+점수 (A동일) | 점수 가중치 (A동일) | 10일 저가 이탈 + 2xATR 손절 | 없음 |
| D | 순수 터틀 | 20일 고가 돌파 | ATR 기반 (자본1%/ATR) | 10일 저가 이탈 + 2xATR 손절 | 없음 |

## 구현 단계

### Step 1: backtest_live_logic.py에 터틀 청산 모드 추가
- `--turtle-exit` 플래그 추가
- `--no-max-hold` 플래그 추가 (14일 제한 해제)
- 터틀 청산 로직: 종가 <= Low_10 이면 매도, 저가 <= 진입가-2xATR 이면 손절

### Step 2: 순수 터틀 진입 모드 추가
- `--pure-turtle` 플래그 추가
- 진입: 종가 > High_20 (20일 고가 돌파)
- 사이징: ATR 기반 (자본 1% / ATR)
- 모든 종목 대상 (테마 무관)

### Step 3: 4전략 비교 실행 모드 추가
- `--compare-turtle` 플래그로 A/B/C/D 순차 실행 후 결과 테이블 출력

### Step 4: 실행 및 결과 문서화
- 백테스트 실행
- docs/backtest_turtle_results.md 업데이트
