# CONTEXT: 대시보드 모바일 반응형 개선

## 변경 이유
- Cloudflare Tunnel 설정으로 `stock.jjjforever.com` 외부 접속 가능
- 모바일에서도 포트폴리오/매매 현황을 빠르게 확인하고 싶은 니즈

## 현재 코드 상태

### dashboard.html (537줄)
- **CSS**: 라인 8~133 (인라인 `<style>`, 약 125줄)
- **HTML 구조**: 라인 135~251 (헤더, 탭, 5개 패널)
- **JavaScript**: 라인 253~535 (API 호출, SSE, 차트)
- **반응형**: 라인 127~132 — 768px breakpoint 1개
- **주요 그리드**: auto-fit/auto-fill + minmax 사용 (요약 카드, 테마 카드)

### login.html (37줄)
- 고정 너비 380px (라인 10)
- 고정 패딩 48px 40px (라인 10)

### 포트폴리오 테이블 열 (10개)
종목, 테마, 수량, 매수가, 현재가, 평가금액, 수익률, 수익금, 보유일, 트레일링

### Trades 테이블 열 (10개)
날짜, 시간, 종목, 매매, 수량, 가격, 금액, 수익률, 수익금, 사유

### Theme History 테이블 열 (6개)
날짜, 테마, 점수, 모멘텀, 수급비율, 뉴스

## 핵심 제약
- Chart.js CDN 사용 → 차트는 자체적으로 responsive:true
- SSE로 실시간 테이블 업데이트 → JS 렌더링 함수도 모바일 대응 필요
- 인라인 CSS/JS → 별도 파일 분리 없이 수정

## 영향 범위
- **직접**: dashboard.html, login.html
- **간접 없음**: 백엔드 API, 데이터 구조 변경 없음
