- BE 손절은 +5%에서 활성화 — 기아는 정확히 4.84%(5% 미달)로 BE 미발동
- 만약 BE 임계 +4.5% 또는 +4%로 완화 시 본 사례에서 -1% 손절가 활성화 → 매수가 -1%인 173,943원 부근에서 보호되었을 가능성
- 단 표본 1건이라 단독 근거 부족

**관련 parameter_suggestion 인용 (W19)**:
- DL이앤씨 (5/4 -8.70% 손절, max_profit=2.53%): *"단기 매매에서 수익 구간(+2.53%)이 발생했을 때 부분 익절 또는 트레일링 스탑으로 전환하지 않으면 손실로 전환될 위험. 명확한 익절 기준 설정 필수"*
- 리노공업 (5/12 -5.99% 손절, max_profit=2.9%): *"보유 중 최고 +2.90% 달성 시점에 트레일링 스탑 활성화 필요. 예: +2.5% 도달 시 -2% 트레일링 스탑 설정"*

**제안 여부**: 관찰 권고 (BE 임계 5%→4% 완화는 표본 더 필요)

### 발견 5: 평시 30일 손절 표본 N=10 누적 (Phase B 트리거 첫 조건 충족)

**증거 데이터**:
```sql
SELECT COUNT(*) AS peacetime_stop_loss_count, MIN(sell_date), MAX(sell_date), ROUND(AVG(profit_rate), 3)
FROM trade_reviews WHERE sell_reason = '손절' AND sell_date >= '2026-04-09';
```

| 항목 | 값 |
|------|-----|
| 평시 손절 누적 | **10건** ✅ |
| 기간 | 2026-04-13 ~ 2026-05-20 |
| 평균 손절률 | **-6.73%** |

**해석**:
- `memory/project_stop_loss_review.md` "Phase B 착수 트리거" 조건 — *"평시 손절 매매 10건 이상 누적"* **충족**
- 다만 분포는 양극화:
  - a) -5% 이상(완만): 2건 (한화오션 -1.06%, GS리테일 -1.62%)
  - b) -5~-7%: 1건 (리노공업 -5.99%)
  - c) **-7~-9% 갭다운: 6건** (66.7%) — 키움증권, DL이앤씨, 한국피아이엠, LS, HPSP, 이오테크닉스
- **-5%로 손절을 좁히면 갭다운 6건은 영향 없음**(이미 -7% 이하), 완만 손절 2건은 더 빠르게 -5% 손절 (한화오션은 -1.06%에서 다행히 거래, GS리테일도 -1.62%)
- **즉 본 평시 표본에서 손절을 -7%→-5%로 좁히면 단순히 손절 발동 빈도만 늘 가능성**. AI review는 한국피아이엠 ts=10 "현 -8% 적절", 리노공업 ts=8 "-6% 적절"로 평가
- 추가로 **갭다운 빈도(60%)가 매우 높아 어떤 손절가도 갭다운 케이스 보호 불가** — 손절가 조정보다 **매수 시점/카테고리 분산** 검토가 더 유효

**제안 여부**: 정보 공유 — **손절가 -5% 상향(좁힘) 안은 본 데이터로는 기각 권고**. 단 strategy-planner 별도 작업으로 정밀 시뮬레이션 필요.
