## 4. 핵심 발견

### 발견 1: 평시 손절 분포는 **갭다운 6건 + 완만 2건 + Day1 Grace 2건**의 3그룹 구조

**증거 데이터**:
```sql
SELECT
  CASE
    WHEN profit_rate <= -7.0 AND hold_days <= 1 THEN 'A: 즉시 갭다운 (D0~D1, -7%+)'
    WHEN profit_rate <= -7.0 AND hold_days >= 2 THEN 'B: 누적 하락 (D2+, -7%+)'
    WHEN profit_rate BETWEEN -6.0 AND -3.0 THEN 'C: 중간 손절 (-3~-6%)'
    ELSE 'D: BE 손절 추정 (-3% 이내, max_profit>=5%)'
  END AS group_label,
  COUNT(*) AS cnt,
  ROUND(AVG(profit_rate),2) AS avg_loss,
  ROUND(AVG(max_profit_during_hold),2) AS avg_max
FROM trade_reviews WHERE sell_reason='손절' AND sell_date >= '2026-04-09'
GROUP BY group_label ORDER BY group_label;
```

결과 (수동 분류):

| 그룹 | 정의 | 건수 | 평균 손실 | max_profit 평균 | 종목 |
|------|------|------|----------|----------------|------|
| **A** | 즉시 갭다운 (hold≤1, -7%+) | **5건** | **-8.21%** | 0.59 | LS, HPSP(5/20), 이오테크닉스, 한국피아이엠, HPSP(4/13)* |
| **B** | 누적 하락 (hold≥2, -7%+) | **3건** | **-8.55%** | 1.63 | HPSP(4/13)→B, 키움증권, DL이앤씨 |
| **C** | 중간 손절 (-3~-6%) | **1건** | -5.99% | 2.90 | 리노공업 |
| **D** | BE 손절 추정 (max≥5%, 실현 -3%이내) | **2건** | -1.34% | 6.02 | 한화오션, GS리테일 |

(\*HPSP 4/13은 hold=2지만 -9.58%로 B 그룹에 정확히 들어감, 위 표는 재분류)

**최종 분류** (재집계):
- **A 즉시 갭다운(hold≤1)**: 4건 (LS, HPSP 5/20, 이오테크닉스, 한국피아이엠) — 평균 -8.16%
- **B 누적 하락(hold≥2)**: 3건 (HPSP 4/13, 키움증권, DL이앤씨) — 평균 -8.67%
- **C 중간 손절**: 1건 (리노공업) — -5.99%
- **D BE 손절**: 2건 (한화오션, GS리테일) — 평균 -1.34%

**해석**: 분포는 단일 봉우리가 아닌 **3개의 클러스터**. 손절선을 단순 -7%에서 -5%로 좁히면 **A,B 그룹(7건)은 영향 없음** (이미 -7% 이하 추락) — 효과 거의 없음. 좁힘은 **현재 C/D 그룹에 해당하지 않는 다른 케이스**에서만 효과가 나타나는데, 본 표본에는 그런 케이스 0건.
