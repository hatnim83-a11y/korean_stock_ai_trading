## 1. 정체 가설 — 데이터 미지지

### 1-A. 만료 청산 = 정체 아니라 "못 오른 약종목"
만료 청산 10건의 **고점(maxp)이 전부 +5.88% 이하**(평균 +2.5%). 트레일링 활성화 임계 +8%에 **단 1건도 도달 못 함** → "올랐다 정체"가 아니라 처음부터 추세 못 만든 약종목. hold_days 5~7(손실 5영업일 만료 주력), **수익 10영업일 만료 도달 0건**.

### 1-B. 롯데쇼핑 = 분할익절 모범 사례
1차 익절 +11.97%(hold 1) / 2차 +19.96%(hold 3) / 잔여 35% holding. 분할익절(+12/+20%)이 고점 근처 차익을 정확히 실현. 잔여만 횡보(설계상 추세 지속 노림용 잔량). **정체 손해 아님.**

### 1-C. 진짜 반납은 트레일링 청산에 (단기 변동성)
트레일링 19건: 고점 평균 +13.7% → 최종 +7.6%, 반납 평균 **6.1%p**. 단 보유일 0~7일(대부분 0~3일) → "장기 정체"가 아니라 **단기 변동성 반납**.

## 2. 옵션별 반사실 (post_trade_prices D+5)

### A — 트레일 타이트닝/조기청산 → 기각
트레일링 청산 후 D+5: **이후상승(조기청산=손해) 8 / 이후하락(청산옳음) 8 / 중립 2.** 정확히 반반. 좁히면 8건(테크윙 +22.6%, LG이노텍 +15.2% 등) 상단 놓치고 8건(LG전자 -19%, 삼현 -19.7% 등) 하락 회피. 일관된 우위 없음 → cap 8% 유지 옳음(trailing-width-cap 결론과 일치).

### B — +15~18% 중간 익절단 → Low 후보
분할익절(+12/+20/+30%)과 트레일링 활성(+8%) 사이 **+14~17% 구간 무방비**는 사실. 고점 12~20% 9건(평균 고점 +15.2% → 최종 +7.97%, 반납 7.2%p)이 타겟. D+5: 상승4(테크윙 +22.6%, SK하이닉스 +7.8% 등) / 하락3(LG전자 -19%, 한국항공우주 -7.5% 등) / 중립2 = **반반**. 도입 시 LG전자류는 구하나 테크윙류 추세 상단 포기. **표본 9건+휩쏘 반반 → Low. 도입한다면 잔여 35% 중 10%p만 부분익절하는 보수적 설계.**

### C — 만료 10→7영업일 → 무의미
만료 청산 hold_days: 5일×6 / 6일×2 / 7일×2 (**10일 도달 0건**). 7로 줄여도 대상 없음. 게다가 만료 후 D+5 하락6/상승2(하락 평균 -7.05%) → 만료가 추가 하락을 회피한 **적절한 청산**.

### 추가 — 거래량/모멘텀 둔화 청산 → 현재 검증 불가
보유 중 일별 거래량/가격 경로 테이블 없어 "모멘텀 둔화" 정의·백테스트 불가. 인프라(일별 경로 적재) 선행 필요.
