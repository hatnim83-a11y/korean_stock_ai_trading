## 4. 핵심 발견

### 발견 1: max 보유기간 제약과 트레일링 폭은 충돌하지 않는다 (가설 기각)
- **증거 데이터** — 트레일링 청산 보유일 분포:
  ```sql
  SELECT CASE WHEN hold_days<=1 THEN '0-1' WHEN hold_days<=3 THEN '2-3'
              WHEN hold_days<=5 THEN '4-5' ELSE '6-7' END AS bucket,
         COUNT(*) n, ROUND(AVG(profit_rate),2) pr
  FROM trade_reviews WHERE strategy_type='trailing_stop' GROUP BY bucket;
  ```
  결과: 0-1일 8건 / 2-3일 3건 / 4-5일 5건 / 6-7일 3건. **최대 7일, 10영업일 만료 임박 0건.**
- **해석**: "넓은 트레일링 때문에 트레일링이 안 걸리고 보유기간 만료로 흘러간다"는 사용자 가설은 데이터상 성립하지 않는다. 트레일링은 만료 한참 전(중앙값 2-3일)에 작동한다.
- **제안 여부**: 정보 공유. 보유기간-트레일링 정합 조정 불필요.

### 발견 2: max_hold 만료 종목은 트레일링 폭 문제가 아니라 "약한 종목" 문제다
- **증거 데이터**:
  ```sql
  SELECT SUM(max_profit_during_hold < 8) below, SUM(max_profit_during_hold >= 8) above
  FROM trade_reviews WHERE strategy_type='max_hold' AND max_profit_during_hold IS NOT NULL;
  ```
  결과: **below 9 / above 0** — 만료 9건(maxp 기록분) 전부 고점 +8% 미달 = 트레일링 활성화 임계(`TRAIL_ACTIVATION_PCT=0.08`) 진입조차 못 함.
  개별: 한화오션 maxp 5.88 / 기아 4.84 / HD한국조선 4.57 / 두산에너빌 3.11 / 나머지 ≤1.5%.
- **D+5 후속**: max_hold 청산 후 평균 -2.96%(하락5/상승3) → 만료 청산이 오히려 하락 회피로 적절.
- **해석**: 만료 종목은 트레일폭이 4%였든 8%였든 트레일링에 걸릴 수 없었다(활성화 미달). 만료를 줄이려면 트레일폭이 아니라 **종목 선정**(약한 종목 진입 차단) 또는 활성화 임계를 손봐야 한다.
- **관련 미결 항목**: project_hold_days_review.md — 만료가 곧 약종목 청산이라 현 10/5영업일은 합리적.
- **제안 여부**: 정보 공유 + 종목선정 별도 관찰 항목.

### 발견 3: ATR cap의 존재는 정당하다 — cap 없으면 트레일링이 사실상 무력화
- **증거 데이터**:
  ```sql
  SELECT stock_name, ROUND(2.0*atr_at_buy/first_buy_price*100,2) atr_pct
  FROM portfolio WHERE atr_at_buy>0 ORDER BY atr_pct DESC;
  ```
  결과: atr_at_buy 박제된 11건(v17 5/23 이후) **전부 2×ATR/first > 8%** (범위 8.1~37.2%: 코스텍시스 37%, 대덕 23%, 피에스케이 22%, 대주 21%, 테크윙 20%...).
- **해석**: cap이 없으면 모든 고ATR 종목의 트레일폭이 10~37%로 폭발 → 트레일링이 손절(-7%) 위로 멀찍이 떨어져 사실상 작동 안 함 → 손절/만료까지 흘러감. **cap 8%는 사실상 모든 고ATR 종목을 "고정 8% 트레일"로 정규화**한다. (부수 발견: ATR/price가 5~18%로 다소 부풀려진 정황 — ATR 계산 단위 점검 권장. 부풀림은 cap 정당성을 오히려 강화.)
- **제안 여부**: cap 유지(섹션 5).

### 발견 4: cap 8%는 catastrophic 1건만 차단, 정상 18건 무손상

- **해석**: cap 8%는 정상 트레일링 18건을 전혀 건드리지 않고 **고ATR 폭발 꼬리(피에스케이 22.49%→8%) 1건만 교정**. 정확히 의도대로 작동.
