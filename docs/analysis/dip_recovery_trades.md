# 거래 전수조사 — 보유 중 손실 깊이 분석

**작성일**: 2026-04-13
**데이터 소스**: `data/trading.db` (`trade_reviews`), pykrx 일별 OHLC
**대상 기간**: 2026-02-20 ~ 2026-04-13 (실전 운용 전 기간)
**스크립트**: `scripts/analyze_dip_recovery.py`

## 목적

손절라인을 현재 수준(ATR 기반 ~-5~-8%, Day1 Grace -8%)에서 **-5% 고정**으로 상향 조정해도 되는지 검토. 보유 중 -5% 이하로 하락했다가 이익으로 마감한 "V자 회복" 사례가 몇 건인지 전수조사.

## 방법론

1. `trade_reviews`에서 모든 매도 기록 조회 (29건)
2. `(stock_code, buy_date)`로 그룹핑 → 고유 포지션 **21건** (분할매도는 동일 포지션)
3. pykrx `get_market_ohlcv_by_date()`로 각 포지션의 보유 기간 일별 **저가** 조회
4. `min_profit_rate = (lowest_low − buy_price) / buy_price × 100`
5. 최종 가중평균 수익률(또는 마지막 sell_price 기준)과 비교

**한계**: 일별 저가 기준이므로 인트라데이 매수가 이후의 저점을 완벽히 반영하지 못할 수 있음 (매수 시각 이전의 저가가 포함될 가능성). 다만 대부분 최저일이 buy_date 당일이라 실운용 시 손절 트리거 판단에는 충분한 근사치.

## 해석

### 손절 -5% 상향 시 영향 시뮬레이션

**현재 구조 (Day1 Grace −8%, 이후 ATR 기반 ~−5~−8%)**:
- 위 2건(LG전자, 테크윙) 모두 Day1(= 매수일)에 하락 → **Grace −8% 덕분에 손절 회피** → 이익 실현

**만약 손절 -5% 고정(Grace 제거)**:
- LG전자(−6.04%), 테크윙(−5.29%) → **강제 손절** (합계 약 +20% 이익 손실)
- 이익 환산(대략): LG전자 +8.91% + 테크윙 +11.63% ≈ +20.5%p → −10%로 역전 (−15%p 스왑)

**만약 Grace 유지 + 손절 -5%로 축소 (Day2 이후만 -5%)**:
- Day1 급락 회복 케이스(이 2건)는 **보호됨**
- 손실 포지션 중 Day2 이후에 추가 하락한 4건(009540, 039030, 403870_03-03, 064760_03-04)은 −5%에서 더 빨리 잘림 → 손실 축소 효과 유

### 손절 -5% 가능성 평가

- **Day1 제외 시**: 이익 마감 11건 중 매수 다음날 이후 저점이 -5% 이하였던 경우는 **없음** (대부분 매수 당일 저점이 최저점)
- **Day1 포함 시**: 2건 (18%) 손절로 전환 → **위험**

**결론**: Day1 Grace Period는 반드시 유지하되, **Day2+ 손절을 -8% → -5%로 축소하는 것은 안전**해 보임. 다만 실전 데이터(20건)가 여전히 적어 통계적 신뢰도는 낮음.

## 권고

1. **−5% 손절 상향 검토는 타당하나, Day1 Grace Period(-8%)는 유지** 필수
2. 변경안 예시:
   - `GRACE_PERIOD_DAYS = 1` (유지)
   - `GRACE_PERIOD_STOP_LOSS = -0.08` (유지)
   - Day2+ 손절 로직: 기존 ATR 기반 → **-5% 고정 또는 max(-5%, ATR)** 로 tighter
3. 데이터가 아직 20 포지션으로 적음 — 1~2개월 추가 운용 후 재평가 권장
4. 매수 당일 급락 패턴(−5% → 회복)은 장 시작 직후 물량 공급 충격으로 보임. 진입 타이밍(`MIN_STRENGTH=50`, 갭다운 -2%)을 이미 강화했으므로 향후 발생 빈도는 줄어들 가능성
