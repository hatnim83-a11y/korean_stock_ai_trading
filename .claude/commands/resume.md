이전 대화에서 진행하던 작업을 재개합니다.

## 지시사항

1. `docs/work-plans/active/` 디렉토리를 확인하여 진행 중인 작업 목록을 파악하라
2. 각 작업의 3문서를 읽어라:
   - `PLAN.md` — 전체 계획과 현재 단계 파악
   - `CONTEXT.md` — 코드 상태와 영향 범위 파악
   - `CHECKLIST.md` — 완료된 항목(`[x]`)과 미완료 항목(`[ ]`) 파악
3. 현재 진행 상황을 요약하여 보고하라:
   - 전체 항목 수 vs 완료 항목 수
   - 다음에 해야 할 작업
   - 주의사항이나 블로커
4. 사용자 확인 후 미완료 항목부터 이어서 작업하라

## 주의사항
- 진행 중인 작업이 여러 개면 사용자에게 어떤 작업을 이어할지 확인한다
- CHECKLIST.md의 이미 완료된 항목을 다시 수행하지 않는다
