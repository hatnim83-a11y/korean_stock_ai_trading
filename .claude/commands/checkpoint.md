현재 진행 상황을 CHECKLIST.md에 업데이트합니다.

## 지시사항

1. `docs/work-plans/active/` 에서 현재 작업의 CHECKLIST.md를 읽어라
2. 이번 대화에서 완료한 작업을 파악하라
3. CHECKLIST.md의 해당 항목을 `[x]`로 업데이트하라
4. 진행 상황 요약을 보고하라:
   - 구현 항목: N/M 완료
   - 검증 항목: N/M 완료
   - 배포 항목: N/M 완료
   - 문서 업데이트: N/M 완료
5. 아직 미완료인 항목 중 다음에 해야 할 것을 안내하라

## 주의사항
- 실제로 완료하지 않은 항목을 체크하지 않는다
- 작업 중 새로 발견된 항목이 있으면 CHECKLIST.md에 추가한다
