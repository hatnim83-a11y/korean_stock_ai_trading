새 작업 계획을 수립합니다.

## 지시사항

1. 사용자의 작업 요청을 분석하여 목표, 범위, 영향도를 파악하라
2. 관련 매뉴얼 챕터가 있으면 `docs/INDEX.md`를 확인하고 해당 챕터를 읽어라
3. 구현 계획을 단계별로 작성하여 사용자에게 제시하라
4. 사용자 승인 후 `docs/work-plans/active/{작업명-kebab-case}/` 에 3문서를 생성하라:
   - `PLAN.md` — 목표, 배경, 구현 단계, 변경 파일 목록, 접근 방식, 롤백 계획, 완료 기준
   - `CONTEXT.md` — 변경 이유, 현재 코드 상태(파일:라인), 핵심 코드 스니펫, 관련 과거 버그, 영향 범위, 작업 중 발견 사항
   - `CHECKLIST.md` — 구현 항목 `[ ]`, 검증 항목 `[ ]`, 배포 항목 `[ ]`, 문서 업데이트 항목 `[ ]`
5. 3문서 저장 완료를 보고하라. 코딩은 3문서 저장 이후에만 시작한다.

## 주의사항
- 계획 승인 전에 코딩을 시작하지 않는다
- 3문서가 저장되기 전에 코딩을 시작하지 않는다
- `docs/work-plans/active/`, `docs/work-plans/completed/` 디렉토리가 없으면 먼저 생성한다
