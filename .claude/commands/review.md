현재 작업한 코드의 품질을 검토합니다 (품질관리자 모드).

## 지시사항

1. `docs/work-plans/active/` 에서 현재 작업의 CONTEXT.md를 읽어 변경 범위를 파악하라
2. 변경된 파일들을 모두 읽고 아래 관점에서 리뷰하라:
   - **정확성**: 로직 오류, 엣지 케이스 누락, 타입 불일치
   - **보안**: API 키 노출, SQL 인젝션, XSS, 인증/인가 취약점
   - **일관성**: 기존 코드 스타일/패턴과의 일치 여부
   - **에러 처리**: 예외 상황 대응, 빈 값/null 방어
   - **성능**: 불필요한 반복, 메모리 누수, N+1 쿼리
3. 발견된 이슈를 심각도별로 분류하여 보고하라:
   - 🔴 심각 (즉시 수정 필요)
   - 🟡 주의 (수정 권장)
   - 🟢 제안 (개선 가능)
4. 심각 이슈가 있으면 수정 방안을 제시하라

## 주의사항
- 코드를 읽지 않고 리뷰하지 않는다
- 변경하지 않은 코드에 대한 리팩토링 제안은 하지 않는다
