현재 작업에 대한 테스트를 수행합니다 (테스터 모드).

## 지시사항

1. `docs/work-plans/active/` 에서 현재 작업의 CHECKLIST.md 검증 항목을 읽어라
2. CONTEXT.md로 테스트 범위를 결정하라
3. 아래 순서로 테스트를 수행하라:
   - **구문 검사**: `py_compile`로 수정된 파일 컴파일 확인
   - **임포트 검사**: 수정된 모듈의 import가 정상 동작하는지 확인
   - **기능 테스트**: CHECKLIST.md 검증 항목 기반 테스트
   - **엣지 케이스**: 빈 값, None, 경계값, 예외 상황 테스트
4. 테스트 결과를 보고하라:
   - ✅ 통과 항목
   - ❌ 실패 항목 (원인 + 수정 방안)
5. CHECKLIST.md 검증 항목을 업데이트하라 (통과 시 `[x]`)

## 주의사항
- code-tester 에이전트를 활용하여 검증한다
- 테스트 실패 시 즉시 수정하지 않고 먼저 보고한다
