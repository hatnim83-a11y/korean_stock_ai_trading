# 분할익절 트리거 하향 분석 (focus:partial_profit, 2026-06-16)

data/trading.db, trade_reviews 74건(2/26~6/16). trade_reviews는 매도이벤트당 1행 → 분할익절 포지션은 1차/2차/3차/트레일링 다행. 포지션 재구성 필수.

## 결정적 컨텍스트 (분석 프레임 자체를 바꿈)
- 현행 config TAKE_PROFIT_1/2/3 = 0.12/0.20/0.30 (**v17, 2026-05-20경 +10/15/20에서 상향**). config.py:337 주석 "v17 +10→+12 상향, 수익 끌기" 명시
- 즉 사용자의 "트리거 하향" 요청 = **v17 상향을 되돌리는 것**. S2(+8/15/25)는 v17 이전보다도 낮음
- **regime split**: v17(+12, buy_date>=5/20) 포지션 = 1차익절 2건 / 전체 9건. pre-v17(+10) = 1차익절 9건 / 전체 43건
- → v17 자체 평가는 표본 2건으로 **불가**. 그러나 pre-v17 +10% 9건이 "트리거를 낮추면 어떻게 되는가"의 자연실험 데이터

## 1차 분할익절 실측 (sell_reason='1차 분할익절', profit_rate)
- pre-v17 7건: 모두 profit_rate 9.95~10.23% (트리거 +10% 정확 발화)
- v17 4건: 롯데쇼핑 11.97, 피에스케이 10.28(불타기로 avg<first), 삼성전자 14.02, LG이노텍 20.47(2차 동시?)
- **분할익절 반납 거의 0** (1차 maxp ≈ profit_rate, 고점서 바로 청산) — 트레일링(반납 6.1%p)과 대조. 익절은 정확한 청산

## 핵심 수혜 그룹: 고점 +8~12%인데 1차 미발화 → 트레일링L1 청산 (9건)
SK하이닉스 maxp14.91/pr10.23, LG전자 14.57/8.91, 티씨케이 11.26/3.45, 심텍 10.86/6.29, 엠케이전자 9.9/4.35, HJ중공업 9.61/5.05, 셀트리온 9.43/5.09, 하나마이크론 9.21/3.82, 삼현 8.46/3.9
- 이들은 +10% 트리거였다면 일부는 잡았을것(maxp>10 = SK/LG전자/티씨케이/심텍 4건). 나머지 5건은 +8~10이라 +10에도 미발화 → +8 트리거(S2/S3)라야 잡음
- **post-sell D+5 반반**: SK하이닉스 +14, 티씨케이 +15.56, 엠케이 +15.83, HJ +20.7 추가상승(일찍팔면 손해) vs LG전자 -11.57, 심텍 -9.7, 셀트리온 -5.3, 하나마 -1.36, 삼현 -16.43 하락(일찍팔면 이득). **트레일링 청산 메모리와 동일한 반반 패턴**

## 추세종목 일찍 판 비용 (상단 기회비용)
- 1차 익절 후 post-sell: 테크윙 D+5 +28%, 네패스아크 +26%, LG이노텍 +22%, 삼성전자 +9% 계속 상승
- 그러나 **1차는 25%만 매도**, 잔여 75%는 트레일링으로 추세 추종 → 일찍 판 비용 = "25% 분량 × 상단 차이"로 한정. 트리거를 +12→+10 낮춰도 추가로 일찍 파는 양은 25%의 일부일 뿐(2%p 더 빨리)
- 즉 추세 상단 손실은 작고, 정체종목 조기실현 이득은 반반. **비대칭 작음**

## 결론
- 트리거 하향의 순효과 = 추세 상단 기회비용(작음, 25%한정) vs 정체 조기실현(반반). **명확한 우위 없음**, 분할익절은 이미 반납 0이라 개선 여지 작은 영역
- **S3(1차만 +10 하향, 2/3차 유지)이 유일하게 방어 가능** — v17 이전 +10이 실측 데이터 풍부, 추세는 2/3차로 보호. 단 이것은 v17의 1차 상향만 되돌리는 것
- 그러나 v17 상향 자체가 표본 2건이라 "되돌릴 근거"도 약함 → **현행 유지 + 관찰** 권고가 정직. 굳이 바꾼다면 S3 Low 신뢰도
- 표본: 1차익절 11건 + 수혜그룹 9건 = Low. v17 데이터 9건 더 쌓일때까지 유보가 정석. 과적합 경고 강함
