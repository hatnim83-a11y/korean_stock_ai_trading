# 정체(횡보) 종목 처리 개선 분석 (focus:trailing 정체, 2026-06-16)

[[trailing-width-cap-finding]] [[trailing-multiplier-dead-param-finding]] 의 자매편. 질문 = "올랐다가 정체하는 종목(롯데쇼핑류) 청산 개선 A/B/C + 추가옵션".

## 데이터 가용성 한계 (필수 전제)
- trade_reviews에 고점 **도달일/정체구간** 필드 없음. max_profit_during_hold(고점%)+hold_days+최종 profit_rate만. position_state=스냅샷 1행, daily_snapshots=계좌단위. **보유 중 일별 가격경로 테이블 부재** → "정체"는 간접추정만(고점높음+반납큼). post_trade_prices(청산후 D+N)는 정상.

## 결정적 사실 (data/trading.db, 스윙 74건 2/26~6/16)
- **롯데쇼핑(사용자 예시)은 정체 손해 사례 아님**: 1차익절+11.97%·2차+19.96%로 잘 청산, 잔여 35%(5/7주) holding +0.17%. 분할익절이 정체를 이미 흡수
- **만료청산 10건 전부 고점 +5.88% 이하**(평균 maxp +2.5%) = 트레일링활성(+8%)구간 진입조차 못한 약종목. "올랐다 정체"가 아니라 **"애초에 못 오름"**. hold_days 5~7(손실5일만료 우세, 10일만료 0건)
- **트레일링 청산 19건**: 고점평균 +13.7%→최종 +7.6%, 반납 6.1%p. 그중 16건이 반납4%p+(평균6.57). 9건이 고점 +12~20%구간(평균 +15.2%→+7.97%, 7.2%p반납) = 옵션B 타겟

## 옵션별 판정 (D+5 반사실)
- **옵션A(정체감지 트레일타이트닝 8%→3%/조기청산)**: 기각. 트레일링청산 후 D+5 = 상승8/하락8/중립2 = **정확히 반반**. 더 좁혀도 휩쏘 위험 동일. cap finding과 동일결론(좁은폭 우위 증거 없음)
- **옵션B(+15~18% 중간익절단 추가)**: 약한 Low. 고점 12~20% 9건 중 D+5 이후상승4(테크윙+22.6/SK하이닉스+7.8/네패스+7.1/HJ+2.1) vs 하락3(LG전자-19/한항우-7.5/펄어비스-4.9) vs 중립2. **여기서도 반반** → 추세종목 상단포기 위험 상존. 단 분할익절(+12)과 트레일링(+8활성) 사이 +14~17% 구간이 무방비인 건 사실. 표본 9건 case-based
- **옵션C(만료 10→7영업일 단축)**: 무의미. 현 만료청산 hold_days 이미 5~7(10도달 0건). 만료 후 D+5 하락6/상승2(avg하락-7%) → 만료청산이 오히려 하락회피로 적절, **단축할 종목 자체가 없음**(만료=손실5일이 이미 빠름)
- **추가(거래량/모멘텀 둔화 청산 등)**: 보유중 일별데이터 부재로 검증 불가. 인프라(일별 경로 적재) 선행 필요

## 결론
- A/C 기각, B만 Low신뢰도 후보(표본9·휩쏘반반·과적합경고). **현행 분할익절+트레일링이 정체를 이미 상당부분 흡수** → 강한 변경 비권고
- 진짜 개선 = 파라미터 아니라 **보유중 일별 가격경로 적재 인프라**(정체 직접판정 가능해짐) + [[trailing-width-cap-finding]]의 종목선정/BE floor
- D+5 반반 = 청산타이밍 미세조정의 알파 한계. 표본 19/9 = Low. 변동성레짐 편향
