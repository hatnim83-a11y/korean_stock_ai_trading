# 트레일링 폭 최적화 분석 (focus:trailing, 2026-06-16)

스윙 trade_reviews 74건(2/26~6/16), 트레일링 청산 19건 표본 기준.

## 핵심 사실 (data/trading.db, 절대경로 /home/hatni/korean_stock_ai_trading/data/trading.db)
- profit_rate/max_profit_during_hold 단위 = **퍼센트**(손절 평균 -7.76% = 손절 -7% 설정과 일치 검증)
- 트레일링 청산 19건: 고점 평균 +13.72% → 최종 +7.62%, **반납 평균 6.1%p**. 분할익절(take_profit)은 반납 0.3%p(고점 근처 청산)
- 트레일링 청산 보유일: 19건 중 11건이 0~3일, 최대 7일. **10영업일 만료 임박 트레일링 청산 0건** → "넓은 트레일링 때문에 만료로 흘러간다" 가설 기각
- max_hold 만료 9건(maxp 기록분) **전부 고점 +8% 미달** = 트레일링 활성화(+8%) 구간 진입 못한 약한 종목. 폭과 무관
- max_hold D+5 평균 -2.96%(하락5/상승3) → 만료 청산이 오히려 하락 회피로 적절

## ATR cap 정당성 (결정적)
- atr_at_buy 박제된 11건(v17 5/23 이후) **전부 2×ATR/first > 8%** (10~37%). cap 없으면 모든 고ATR 종목 트레일폭 폭발 → 트레일링 무력화·손절/만료까지 흘러감
- 즉 cap 8%는 사실상 모든 고ATR 종목을 "고정 8% 트레일"로 만듦. ATR 비례는 이미 거의 무력
- 코스텍시스 2×ATR/first=37%, 대덕 23%, 피에스케이 22% → ATR 계산이 다소 부풀려진 정황(보통 ATR/price 2~5%인데 여기선 5~18%). 이 노이즈가 cap 정당성 강화

## cap 값 선택 (휩쏘 검증)
- cap 8%(현행): 19건 중 **피에스케이홀딩스 1건만 교정**(26%p반납→8%). 정상 18건 무영향 → catastrophic 꼬리만 차단, 정상 동작 무손상. 정확한 설계
- cap 6%: 3건 영향 / cap 5%: 8건 영향 / cap 4%: 16건(사실상 전건 4%고정)
- 반납 5%+ 8건의 D+5: 좁히면 추가상승포기(손해) 3건 vs 하락회피(이득) 3건 vs 중립 1건 = **반반**. 좁은 cap 일관 우위 증거 없음
- 단순 반사실(좁힐수록 가상수익↑, cap4=9.78% vs cap8=8.59%)은 **청산 후 추가상승 무시**한 편향. D+5 반반이 이를 반박

## 결론
- **cap 8% 유지 권고**(좁히지 말 것). 고정 5% 회귀도 비권고 — 정상 트레일링까지 일률 압축해 상방 포기
- 진짜 레버: 트레일폭이 아니라 ① 종목선정(max_hold 만료 = 약한 종목) ② ATR 계산 단위 검증(부풀림 의심) ③ BE floor(피에스케이가 cap에도 -9.45% 청산된 건 BE 바닥 미작동 — TRAIL_BE_FLOOR_ENABLED 6/16 동시 도입이 이 보완)
- 표본 19건 = Low~Medium 신뢰도. 변동성 레짐 편향 가능, 계속 관찰
